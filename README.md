# Macadam desktop releases

Official desktop binaries, release notes, checksums and release manifests for Macadam.

The first desktop alpha is being prepared. No desktop release is published here yet.

| Platform | Architectures |
| --- | --- |
| macOS | ARM64 / Apple Silicon |
| Windows | x86-64 and ARM64 |
| Linux | x86-64 and ARM64 |

Each published release will identify the app version, kernel version, source revision and target architecture. A complete release is published only after all required targets finish their build, package and qualification checks.

Downloads and installation instructions will be linked from [the Macadam website](https://macadamcad.com/). Individual releases will include their actual platform requirements, known issues and third-party notices.

For plugin development, use the separate public [Macadam plugin SDK](https://github.com/macadamcad/macadam-plugin-sdk), which contains API documentation, type definitions and examples.

This repository distributes desktop releases. Application source is maintained separately.
